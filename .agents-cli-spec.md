# Agent Spec: Hunger Games Middle School Exam Assessment & Teacher Assistant Agent

## Overview
An educational multi-agent system designed for middle school teachers that assesses student exams on Suzanne Collins' *The Hunger Games*. The system receives an exam rubric, an answer key, and student exam submissions (containing short factual answers and long analytical essays). 

The system operates through a sequential multi-agent evaluation pipeline with a conversational Teacher Dialogue Coordinator:
1. **PII Masking & Anonymization Vault**: Redacts student Name and Student ID, assigning an isolated cryptographic pseudonym token (`STUDENT_ANON_XXXX`) to ensure unbiased grading and privacy compliance.
2. **Sequential Evaluation Pipeline**:
   - **Correctness Assessor Agent** (routed to Gemini 2.5 Flash for rapid, accurate factual verification against the canon and answer sheet).
   - **Writing Quality Assessor Agent** (routed to Gemini 2.5 Pro for deep qualitative rubric analysis of vocabulary, text evidence, structure, and grade-level reasoning).
   - **Scorecard Synthesizer**: Aggregates criteria into a structured student scorecard with breakdown, letter grade, and actionable pedagogical feedback.
3. **Human-in-the-Loop (HITL) Gate**: Flags any student submission with an overall score < 60% (failing / intervention needed) or > 90% (excellence / verification), or with > 30% discrepancy between correctness and writing quality, pausing for teacher review and confirmation.
4. **Interactive Teacher Dialogue Coordinator**: Enables the teacher to converse with the agent, ask questions, review scorecards, and request targeted section re-evaluations (re-dispatching the specific specialist agent with teacher feedback) or apply direct grade overrides with complete audit logging and score history diffs.
5. **Observability & Infrastructure**: End-to-end OpenTelemetry distributed tracing, structured JSON logging with explicit Intent vs. Outcome captures, automated PII scrubbing, persistent session state, async memory consolidation, automated evaluation suite against a golden dataset, Terraform IaC, and GitHub Actions CI/CD.

`python` (ADK Python ~= 1.7.0, Python 3.11+)

## Example Use Cases
### Case 1: Standard Sequential Assessment & Scorecard Generation
- **Input**: Teacher submits a student exam markdown for "Student: Katniss Fan, ID: 10482" containing answers to 3 short factual questions and 2 long essay questions.
- **Processing**:
  1. Anonymizer extracts Name & ID into secure vault; replaces with `STUDENT_ANON_E7B1`.
  2. Correctness Agent checks factual answers against Hunger Games lore and answer key (e.g., Katniss volunteering for Prim, Rue's mockingjay signals, tracker jacker venom defense).
  3. Writing Quality Agent analyzes essay structure, middle school 7th-8th grade literacy standards, use of textual citations, and thematic reasoning (e.g., Capitol control vs. rebellion symbolism).
  4. Scorecard Synthesizer calculates composite score (86/100).
- **Output**: Detailed scorecard presented to teacher with per-question breakdowns and constructive student feedback under pseudonym.

### Case 2: Human-in-the-Loop (HITL) Flagging
- **Input**: A student answers Question 4 vaguely, scoring 52% overall (below 60% threshold).
- **Processing**: Synthesizer detects score < 60%. Sets `requires_human_review=True` with `review_reasons=["SCORE_BELOW_PASSING_THRESHOLD"]`.
- **Output**: Agent halts automated finalization and prompts teacher: "Score flagged for human review (52%). Please review breakdown or confirm grade."

### Case 3: Conversational Teacher Feedback & Targeted Regrading
- **Input**: Teacher: "On question 2, the student mentioned the bow and arrow from the Cornucopia; consider partial credit for weapon familiarity. Please regrade correctness for Q2."
- **Processing**: Coordinator parses feedback, re-invokes only the Correctness Specialist Agent with the teacher's note injected, recalculates Q2 score, updates the scorecard in session state, and logs an audit trail: `Q2 Correctness updated from 1/5 to 4/5. Rationale: Teacher note on weapon familiarity`.
- **Output**: Revised scorecard with audit diff and updated final grade.

### Case 4: Teacher Score Override with Audit Trail
- **Input**: Teacher: "Override writing quality on essay 1 to 18/20 due to student's 504 accommodation."
- **Processing**: Coordinator executes `override_section_score_with_audit` tool, recording prior score, new score, and teacher justification.
- **Output**: Updated scorecard reflecting manual override with badge `[Teacher Override: 504 accommodation]`.

## Tools Required
1. `anonymize_student_submission(raw_submission: str) -> AnonymizedSubmissionResult`:
   - Strips student name and student ID using regex/NER, stores mapping in an encrypted/isolated vault, and returns pseudonymized markdown.
2. `restore_student_identity_vault(token: str, teacher_auth: bool) -> StudentIdentityResult`:
   - Securely resolves pseudonym token back to student identity only upon verified teacher completion.
3. `evaluate_factual_correctness(question_id: str, student_answer: str, answer_key: str, rubric_criteria: str) -> CorrectnessEvaluation`:
   - Assesses factual accuracy against Hunger Games canon and provided answer key.
4. `evaluate_response_writing_quality(question_id: str, student_answer: str, rubric_criteria: str) -> QualityEvaluation`:
   - Evaluates textual evidence, organization, vocabulary, and analytical reasoning against middle school standards.
5. `generate_student_scorecard(evaluations: list[QuestionScoreItem], rubric_weights: RubricWeights) -> StudentScoreCard`:
   - Compiles section scores, checks HITL criteria (<60%, >90%, >30% discrepancy), and outputs formatted scorecard.
6. `trigger_human_in_the_loop_review(scorecard_id: str, reasons: list[str]) -> ReviewPauseState`:
   - Pauses execution and creates a review gate requiring human teacher approval.
7. `regrade_assessment_section(section_id: str, agent_target: str, teacher_feedback: str) -> SectionRegradeResult`:
   - Re-dispatches only the targeted specialist agent (correctness or quality) with the teacher's instruction.
8. `override_section_score_with_audit(section_id: str, metric: str, new_score: float, max_score: float, justification: str) -> ScoreOverrideAuditResult`:
   - Applies an explicit teacher override with full audit trail (prior score, new score, timestamp, teacher rationale).

## Constraints & Safety Rules
1. **Zero Hallucination Canon Adherence**: Factual scoring must be strictly grounded in Suzanne Collins' *The Hunger Games* (Book 1) and teacher's answer key. Speculative claims or details from unrelated films/books must be flagged.
2. **Strict PII Protection**: Real student names and IDs must never appear in LLM evaluation prompts, OpenTelemetry span attributes, or structured JSON logs. All processing uses `STUDENT_ANON_XXXX`.
3. **Middle School Appropriate Expectations**: Feedback must be pedagogically sound, encouraging, constructive, and calibrated to 7th-8th grade reading/writing levels.
4. **Non-destructive Audit Trails**: Teacher overrides and re-evaluations must never silently overwrite history. Both original and modified scores must be preserved in the session audit log.
5. **Human Gate Enforcement**: Final grade recording for flagged submissions (<60% or >90%) cannot be completed without explicit teacher confirmation.
